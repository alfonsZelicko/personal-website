### The Essentials (Daily Drivers)

These are the tools I use almost every day to check compatibility, documentation, or quick fixes.

- [Can I Use](https://caniuse.com/) – The gold standard for browser support tables.
- [MDN Web Docs](https://developer.mozilla.org/) – Best documentation for Web standards.
- [Bundlephobia](https://bundlephobia.com/) – Check the cost of adding a npm package to your bundle.
- [SVGOMG](https://jakearchibald.github.io/svgomg/) – Essential for optimizing SVGs before using
  them.
- [DevDocs](https://devdocs.io/) – Offline-capable combined API documentation browser for dozens of
  languages and frameworks.
- [Regex101](https://regex101.com/) – The best online regex tester with live explanation and a
  debugger. In AI era mby little obsolete, but it is good to have some backup.
- [Explainshell](https://explainshell.com/) – Paste any shell command and get a breakdown of what
  each part does - back in the days it was cool! Today we have AI, but I want to have it here.
- [Excalidraw](https://excalidraw.com/) - A simple tool for creating a quick mind maps, diagrams,
  etc. ... effective during conversations on tinder date, etc. ... 8-)

### AI & LLM (Offline & Open Source)

Since everyone is into AI now, here are some links for running things locally or finding pre-trained
models.

- [Ollama](https://ollama.com/) – The easiest way to run LLMs (Llama 3, Mistral, etc.) locally on
  your machine.
- [Hugging Face](https://huggingface.co/models) – The "GitHub of AI" where you can find thousands of
  pre-trained models to download.
- [LM Studio](https://lmstudio.ai/) – A GUI for discovering, downloading, and running local LLMs.
- [LocalAI](https://localai.io/) – Self-hosted, community-driven local OpenAI-compatible API.
- [Open WebUI](https://openwebui.com/) – A polished, self-hosted chat UI that connects to Ollama or
  any OpenAI-compatible backend.
- [Jan](https://jan.ai/) – Another clean offline-first AI desktop app; good alternative to LM
  Studio.
- [AnythingLLM](https://anythingllm.com/) – Turn any document into a chatbot, runs fully locally.
  Great for RAG experiments.

### YouTube Alternatives & Free Media

Because sometimes you don't want the algorithm watching you watch videos.

- [FreeTube](https://freetubeapp.io/) – Desktop YouTube client with no ads, no tracking, and a
  built-in subscription manager. Fully offline-capable via local API.
- [Invidious](https://invidious.io/) – Open-source YouTube frontend you can self-host or use via
  public instances. No account needed.
- [Piped](https://piped.video/) – Another privacy-respecting YouTube frontend, faster than Invidious
  and with SponsorBlock built in.
- [Newpipe](https://newpipe.net/) – The FreeTube equivalent for Android. Background play, downloads,
  no Google.
- [Odysee](https://odysee.com/) – Decentralized video platform built on LBRY. Home to a lot of tech
  and indie creators.
- [PeerTube](https://joinpeertube.org/) – Federated, self-hostable video platform. Think Mastodon
  but for video.
- [Internet Archive](https://archive.org/) – Millions of free books, films, music, and software.
  Also home of the Wayback Machine.

### Web Experiments & Niche Tools

Cool, weird, or extremely specific tools that might come in handy one day.

- [Champagne](https://champagne.pages.dev/) – A very minimalist, "brutalist" approach to web design
  inspiration.
- [CSS Layout Generator](https://layout.bradwoods.io/) – Visually build complex CSS layouts (Grid,
  Flexbox). Yes. From time to time I am using it :-))
- [Tally](https://tally.so/) – The simplest way to create forms (looks like Notion).
- [Realtime Colors](https://www.realtimecolors.com/) – Test color palettes on a real website mockup
  instantly.
- [Radio Garden](https://radio.garden/) – Spin a 3D globe and tune into live radio stations from
  anywhere in the world. Oddly addictive. Cool on parties - to show what kind of music listening
  different people in different countries...
- [Google Earth Web](https://earth.google.com/web/) – No install needed. Fly around the planet,
  explore 3D cities, check Street View.
- [Shademap](https://shademap.app/) – Simulate sun position and shadows anywhere on Earth at any
  time of year. Great for checking which side of the street gets sun.
- [Windy](https://www.windy.com/) – Stunning real-time wind, rain, and weather visualization on a
  globe. Way more fun than a weather app.
- [The True Size Of](https://www.thetruesize.com/) – Drag any country to see how it really compares
  in size to others. Mercator projection is a lie.
- [Worldometers](https://www.worldometers.info/) – Real-time counters for population, CO₂, energy,
  and more. Good for perspective.
- [Hacker News](https://news.ycombinator.com/) – Tech news aggregator run by Y Combinator. Still the
  best place for signal over noise.
- [Marginalia Search](https://search.marginalia.nu/) – A search engine that deliberately surfaces
  small, non-commercial websites. The old web lives here.

### Performance & Security

- [PageSpeed Insights](https://pagespeed.web.dev/) – Google's tool for analyzing web performance.
- [Security Headers](https://securityheaders.com/) – Quickly check if your site is missing important
  security headers.
- [Web Check](https://web-check.xyz/) – All-in-one OSINT tool for any website.
- [SSL Labs](https://www.ssllabs.com/ssltest/) – Deep analysis of your server's SSL/TLS
  configuration. Essential before going live.
- [GTmetrix](https://gtmetrix.com/) – Another solid performance analyzer; gives you Waterfall charts
  and historical tracking.
